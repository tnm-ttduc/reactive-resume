# CV Input Corpus — Sprint 0

Đặt 3 file CV dùng cho kiểm thử Sprint 0 vào thư mục này.

## Quy ước

- Định dạng ưu tiên: PDF hoặc DOCX.
- Tên gợi ý: `cv-01.pdf`, `cv-02.docx`, `cv-03.pdf`.
- Không commit các file CV vào Git. `.gitignore` đã chặn toàn bộ file trong thư mục, ngoại trừ README này.
- Ưu tiên CV đã ẩn hoặc thay thế tên, email, số điện thoại, địa chỉ và thông tin định danh.
- Chỉ sử dụng file mà đội dự án có quyền dùng cho nghiên cứu và kiểm thử.
- Không đặt API key, mật khẩu hoặc tài liệu ngoài phạm vi CV vào đây.

## Mục tiêu lựa chọn

Nếu có thể, ba file nên đại diện cho:

1. CV ATS một cột, 1–2 trang.
2. CV corporate hoặc hai cột, có tiếng Việt.
3. CV dài hoặc có layout phức tạp để kiểm tra parser và pagination.

Sau khi file được đặt vào thư mục, feature matrix sẽ ghi checksum, định dạng, số trang và tình trạng quyền sử dụng mà không ghi lại nội dung PII.
